# 基于AI大模型的客服问答系统

## 注意事项

### AI客服问答系统

请将qa-service模块中的application.yml,将其中的deepseek的api key替换为自己的。

若此前没有申请过api key请从https://platform.deepseek.com/api_keys申请，且需要充值使用

数据库sql语句已在文件中给出,数据库配置根据自己实际在application.yml文件中修改。

其它配置文件如nacos可根据自己需要修改。

前端文件为fronted-vue3。
